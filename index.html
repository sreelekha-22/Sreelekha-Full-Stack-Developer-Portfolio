Vykronis — Autonomous Incident Response

Flagship

A closed-loop, human-gated incident-response platform. Detects production anomalies, investigates root cause with a tool-constrained AI agent (with deterministic rule-based fallback), gates every action through a fail-closed policy engine, and remediates only after explicit human approval.

  • 9 Spring Boot microservices on 14 Maven modules, 13-container Docker Compose stack
  • Event-driven core — 6 Kafka topics with versioned JSON-Schema contracts (metrics, traces, JFR, alerts, deployments, remediation)
  • Kafka Streams correlation engine — 60s windowed detection with GlobalKTable deployment join, ranked severity
  • 9-state incident state machine persisted in PostgreSQL via Flyway; every transition auditable
  • Tool-constrained AI agent — hypotheses never fabricated; deterministic fallback when infra degrades
  • Fail-closed policy matrix — service-to-service automation denied for production; only a named human approver can authorize
  • Verified end-to-end — 14-event synthetic burst drove OPEN → HYPOTHESIS_READY → AWAITING_APPROVAL → REMEDIATING in 0.8 min on a 7.9 GB laptop

lessongen — Self-Evaluating Lesson Generator

Agentic AI

An agentic generate → evaluate → regenerate loop that writes a lesson, judges it against a hard pass/fail rubric, and regenerates until it clears the bar — shipping the verified lesson together with a full rejection-log audit trail.

  • 13 checkpoints, no partial credit — deterministic (textstat, wordfreq, parse) + LLM-judge hybrid
  • Self-evolving memory — append-only JSONL event log; rubric thresholds adapt within hard caps, never removed
  • Audit the judge — golden-set harness measures stability & ground-truth agreement; unstable judges fail CI
  • Cost & provenance — token usage, USD estimate and git sha recorded per run
  • Model-agnostic — LiteLLM across OpenAI / Anthropic / Ollama; deterministic stub runs offline with no API key
