# 🚀 **Developer Portfolio – Full Stack & AI Projects**

A collection of production-ready **full stack**, **ML-powered**, and **backend engineering** projects showcasing expertise in **React, Node.js, Spring Boot, Python, Flask, LSTM, MongoDB, and more**.
Each project demonstrates real-world problem solving, scalable architecture, and strong development practices.


## 📌 **Projects Overview**

### 🔗 1. **UrlShorty** (Java + Spring Boot)

A URL shortening service similar to Bitly.
Features:

* RESTful API with Spring Boot
* URL hashing & redirection
* MongoDB storage
* Clean DTO-layered architecture
* Easy deployment-ready structure

**🔗 Project Link:** [UrlShorty](https://github.com/sreelekha-22/UrlShorty)



### 🧠 2. **Fake News Detection** (React + Flask + LSTM Model)

AI-powered web application that detects **fake news in real-time**, trained on a **Kaggle dataset** using LSTM (94% accuracy).

Features:

* React-based frontend
* Flask API backend
* Deep learning model (LSTM)
* Confidence score output
* Scalable + deployable architecture

**🔗 Project Link:** [Fake News Detection](https://github.com/sreelekha-22/ML_projects/tree/main/Fake_News_DetectionHK)


### 📅 3. **Appointments Made Easy** (Node.js + Express + React)

A scheduling system with **email alerts & booking management**, built for seamless appointment handling.

Features:

* Node.js + Express backend
* React UI
* Booking + email notifications
* REST APIs & modular structure
* Ready for production use

**🔗 Project Link:** [Appointments Made Easy](https://github.com/sreelekha-22/Appointments-Made-Easy)


### 🎓 4. **Absentra – Leave Management System** (React + RTK)

A responsive LMS (Leave Management System) where employees can apply for leave and admins can manage requests.

Features:

**🔗 Project Link:** [Absentra](https://github.com/sreelekha-22/Absentra)

Full-stack video content platform with authentication, filtering & admin features.

Features:
